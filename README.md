# Voz que Clama — protótipo inicial

Este é um protótipo local da plataforma.

## Como abrir
1. Extraia o ZIP.
2. Abra a pasta.
3. Dê dois cliques em `index.html`.
4. O protótipo abrirá no navegador.

## O que já está desenhado
- Página inicial
- TV digital
- Rádio
- Podcast
- Estudos
- Cursos (área futura)
- Transmissões ao vivo (área futura)
- Assistente de IA (demonstração)
